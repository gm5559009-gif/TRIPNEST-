TRIPNEST · OBJECTIVES 05 / 11
04 · ARCHITECTURE & TECH STACK

Fast, modular, and zero-latency.

Frontend & Routing

  • React 18: Component-driven UI with Context API (AuthContext) and custom hooks
  • React Router v6: Role-protected routes (/user, /admin) via ProtectedRoute
  • Vite 5: Instant HMR dev server & optimized production bundling

Data & Design System

  • Reactive Store (storage.js): localStorage persistence with in-memory fallback & cross-tab event sync
  • Editorial UI: Playfair Display + DM Sans, custom SVG icon library, @media print E-Tickets
  • Zero External Bloat: Pure CSS charts, modals, and state transitions
